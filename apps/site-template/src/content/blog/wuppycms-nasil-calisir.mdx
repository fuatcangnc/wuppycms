Adım adım akış şöyle:

1. **Editör:** CMS'te frontmatter formunu doldurur, gövdeyi yazarsın.
2. **Commit:** Kaydet, GitHub API'siyle atomik commit olarak repoya düşer.
3. **Build:** GitHub Actions `pnpm build` çalıştırır (ücretsiz CI).
4. **Deploy:** Build çıktısı CDN'e basılır.

> Kod senin reponda yaşar; WuppyCMS sadece editör ve boru hattıdır.
