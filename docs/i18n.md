# i18n (yerelleştirme) süreci

Kaynak dil **Türkçe** (`src/lib/locales/tr.yaml`): anahtar ve anlamın tek
doğrusu. Arayüzün **açılış dili İngilizce**dir (`DEFAULT_LOCALE = "en"`);
kullanıcı seçimi `wuppycms:locale` anahtarında kalıcıdır. Diğer diller aynı
klasörde dosya-başına-dil YAML olarak yaşar; yeni dil eklemek için dosyayı
koymak yeterlidir (kayıt gerekmez — Vite derlemede bulur). Eksik anahtar
sırayla: istenen dil → `tr` → anahtarın kendisi (arayüzde görünür ki eksik
çeviri sessizce kaybolmasın).

## Kullanım (kod)

```ts
import { t } from "@/lib/i18n";
t("sidebar.media");                     // "Media" (açılış dili en)
t("trash.selected", { count: 3 });      // {count} yer tutucusu
```

- Anahtarlar nokta yoluyla gruplanır (`sidebar.*`, `review.*`, `status.*`…).
- Yer tutucular süslü parantez: `{count}`. Adlar çeviride **değişmez**,
  sıraları değişebilir.
- Pilot kapsam: kenar çubuğu ve yeni yüzeyler (medya/inceleme/çöp/panel).
  Eski yüzeyler kademeli taşınır; taşınan dize dosyadan çıkarılıp `t()` ile
  okunur.

## Denetim

```bash
node scripts/check-locales.mjs
```

Her locale dosyasını kaynağa karşı doğrular: anahtar kümesi **birebir**,
yer tutucu adları aynı, boş değer yok, dosya satır sonuyla biter. CI/PR
kapısıdır; `docs/e2e-conventions.md`'deki test kapılarıyla birlikte koşulur.

## Çeviri katkısı kuralları

1. **Önce issue:** dil adıyla bir issue açın ("Fransızca yerelleştirme");
   çakışmayı önlemek için atama beklenir.
2. **Yalnız locale dosyası:** PR yalnız `src/lib/locales/<dil>.yaml` ekler/
   günceller; kod, script, doküman değişmez. Başka dilin düzeltmesi kendi
   PR'ında gelir.
3. **Yorumlar çevrilmez:** `tr.yaml`'daki yorumlar bağlam içindir; sırasıyla
   ve birebir korunur.
4. **Dil kodları:** Firefox l10n geleneği — mümkünse kısa kod (`fr`, `de`),
   gerekirse tam kod (`pt-BR`, `zh-CN`).
5. **Kalite:** makine çevirisi kabul edilir ama **gözden geçirilmiş** olmalı;
   kısa arayüz dizelerinde teknik terimler bağlama göre seçilir
   (ör. "merge" = birleştir).
6. `node scripts/check-locales.mjs` hatasız olmalı; PR şablonunda çıktıyı
   paylaşın.

## Neden YAML ve neden kaynak dil tr?

- YAML, çevirmen için JSON'dan okunur ve yorum taşır (Sveltia deseni).
- Ürün Türkçe doğdu; kaynak dilin tr olması "çeviri kokusu"nu önler. İngilizce
  (`en.yaml`) ürünün açılış dilidir (`DEFAULT_LOCALE`); lansman dili olarak
  ilk o görünürlür, tr ikinci dil olarak korunur. E2E suitleri `login()`
  üzerinden bilerek `tr`ye sabitlenir; İngilizce akışı `e2e-editor-layout`
  doğrular.
