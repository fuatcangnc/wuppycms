+ Koleksiyon listesi: arama, klasör gezinme, sıralama, çoklu seçim, silme, önizleme linki
+ Doküman düzenleme: markdown round-trip, slug/folder düzenleme, discard, commit
+ Özel (geleneksel olmayan) koleksiyon desteği
+ Wryte referans seti okundu ve envanterlendi (`skills/wryte/ARTICLES-FEATURES.md`, 54 ekran görüntüsü)
+ **P0 — Editör TAMAM (mdxeditor.dev):** `MdxBodyEditor` — Yaz/Böl/Oku modları, araç çubuğu (başlık, liste, link, görsel, tablo, kod bloğu), **Odak** (tam ekran) modu, medya entegrasyonu (panodan/bırakılan görsel → otomatik yükleme; toolbar "Medyadan ekle" → seçici), MDX/JSX korunur (`suppressHtmlProcessing` + `jsxPlugin`). Autosave = IndexedDB taslak yedeği (④); git commit'i bilinçli olarak kullanıcıda ("Kaydet") — ADR 0006. Harness: `e2e-draft-backup.mjs` yeni editöre uyarlandı, **15/15 ağsız**.
+ **P1 — Durum + frontmatter paneli TAMAM:** başlık altında **durum çipi** (Taslak/İnceleme/Hazır → frontmatter `status`, `setDocField` ile dosyaya yazılır); sağda **meta paneli**: Görsel (alan formu) / **YAML** (elle düzenle → Uygula, yeni anahtar eklenebilir) / **MD** (tam dosya, salt okunur) + **hazırlık skoru** (ağırlıklı 0-100, madde listesi) + **arama önizlemesi** (Google benzeri) + **OG kartı** (kapak alanı + medya seçici + canlı önizleme). Harness `e2e-meta-panel.mjs` (:4396): **15/15 ağsız**. Harness gerçek bir parser hatası yakaladı: Unicode frontmatter anahtarları (`özelNot`) üst-seviye sayılmıyor, önceki değere yapışıyordu — `parseDoc` düzeltildi + test.
+ **P2 — Sürüm geçmişi + diff TAMAM:** meta panelde **Geçmiş** sekmesi (dosya başına commit listesi), **"Anlık görüntü"** (kirliyse etiketli commit; git'te her kayıt zaten sürüm — ADR 0006 ruhu), sürüme tıkla → **satır diff'i** (LCS, `lib/admin/diff.ts`; eklenen/silinen renkli) → **"Bu sürümü yükle"** (forma yükler, kirli işaretler; geri dönüş de normal commit). `saveDoc` → `commitDoc` olarak sadeleşti (Kaydet + Anlık görüntü aynı yol). Harness `e2e-history.mjs` (:4394): **14/14 ağsız** (snapshot commit'i, diff satırları, sürüm geri yükleme + dosya kanıtı).
+ **P3 — Pano / Takvim / Çöp TAMAM:** kayıt listesinde **Liste/Pano/Takvim** anahtarı (adreste `?view=` — ADR 0005); **Pano**: frontmatter `status` kolonları, kartı sürükle-bırak → etiketli commit (`durumu Hazır`); **Takvim**: `date` alanına göre ay ızgarası, günden doküman açma; **Çöp**: silme artık **yumuşak** (`_trash/<yol>`e taşınır), çöp görünümünde **Geri yükle** / **Kalıcı sil** (ikisi de normal commit — ADR 0006). Özet üretimi artık `status` taşıyor; `parseFrontmatterScalars` Unicode anahtar düzeltmesi. Harness `e2e-board-trash.mjs` (:4393): **21/21 ağsız** (sürükle-bırak commit'i, takvim, çöp döngüsü — hepsi dosya bayt kanıtlı).
+ **P4 — Zamanlama TAMAM:** `publishAt` frontmatter'ı + **yürütücü** (`src/lib/schedule.ts` saf kurallar: `isDue/pickDueDocs`; `POST /api/schedule/run` tek repo ya da kullanıcının tüm projeleri; **Cron Trigger** `*/15` → `worker.ts scheduled` → tüm projeler, proje sahibinin token'ı). Zamanı gelen doküman `status: ready` olur ve commit atılır (`zamanı geldi — yayına hazır`); idempotent. Meta panelde **Zamanlama** bölümü (datetime-local + durum: Zamanlanmadı/Planlandı/Zamanı geldi/yayında). **Medya alt/caption D1'den repoya taşındı:** `.wuppycms/media.json` manifesti (OSS taşınabilirlik — ADR 0006'daki bilinen sapma kapandı); D1 tablosu geçmiş için duruyor. Harness `e2e-schedule.mjs` (:4392): **16/16 ağsız** (yürütücü + idempotentlik + gelecek tarih + manifest döngüsü).
+ **P5 — BYO AI TAMAM:** **Ajan ile kullan** diyaloğu iki sekmeli oldu — "Kodlama ajanı" (mevcut) + **"Sağlayıcı"**: OpenAI-uyumlu (OpenAI/Groq/OpenRouter/Ollama — serbest baseUrl) ya da Gemini; anahtar **şifreli D1** (`ai_settings`, `TOKEN_ENCRYPTION_KEY`), tarayıcıya hiç inmez, repoya asla yazılmaz. **İçerik üretimi:** editörde "AI ile üret" → istem + ton (4) + uzunluk (3) + dil + anahtar sözcük → `POST /api/ai/generate` (worker sağlayıcıya gider; Gemini şekli de destekli) → önizleme → "Gövdeye ekle" (kirli; kullanıcı Kaydet der). Sağlayıcı hataları anlamlı mesajla döner. Harness `e2e-ai.mjs` (:4391): **11/11 ağsız** (sahte OpenAI ucu mock sunucuda; ayarsız/başarılı/ölü-sunucu yolları).
+ **Parity turu 1 TAMAM (P2+ borçları):** **`media://` bağı** üretimi + detayda **"Bağı çöz"** (media-uri → relative çözümü gösterir); **gösterim genişliği %** (manifest + seçici genişlik ayarlıysa `style="width: N%"` ile HTML img ekler — mdxeditor normalizasyonunda `width` yüzdesi düşerken `style` sağlam kalıyor, deneyle seçildi); **odak noktası** (kırpma panelinde mini önizleme, manifeste yazar); **MD/HTML kopyala** araç çubuğu düğmeleri; **h1-h6/paragraf** zaten araç çubuğunda (BlockTypeSelect — borç kapandı). `refreshMedia` yarışı düzeltildi (meta atomları liste çizilmeden yazılır). Harness `e2e-parity.mjs` (:4390): **14/14 ağsız**.
+ **Parity turu 2a TAMAM:** **Add Collection sihirbazı** (kenar çubuğu "+" → anahtar/klasör/desen/alanlar → `src/content.config.ts`'e `defineCollection` bloğu + `export const collections` güncellemesi, commit'li; `refreshCollections` ile anında görünür) ve **Embed desteği (12 sağlayıcı)**: `lib/admin/embeds.ts` saf tanıma motoru (YouTube/Vimeo/X/Instagram/TikTok/Spotify/SoundCloud/CodePen/CodeSandbox/Gist/Figma/Maps; iframe ya da blok alıntı üretir), araç çubuğunda "Embed" diyaloğu (tanınan sağlayıcı canlı gösterilir, bilinmeyen bağlantıda Ekle kapalı). + **Parity turu 2b-i TAMAM — ekip/davetler:** `project_members` + `project_invitations` (D1, migration 0006); sahip davet üretir (bağlantı paylaşılır — e-posta gönderimi yok), üye kendi hesabıyla `/invite?token=…` sayfasından kabul eder (e-posta eşleşmesi sunucuda doğrulanır), sahip üye çıkarır / davet iptal eder. + **Parity turu 2b-ii TAMAM — Review & PR akışı:** "İncelemeye gönder" mevcut içeriği `review/<slug>-<zaman>` dalına commit eder ve PR açar (**ana dal değişmez**); **İncelemeler** görünümü (kenar çubuğu) açık PR'ları karar çipiyle listeler; **Diff** diyaloğu (compare + dosya başına satır diff'i), **Onayla** / **Değişiklik iste** (GitHub reviews), **Birleştir** (içerik ana dala girer = yayın), **Kapat**.
